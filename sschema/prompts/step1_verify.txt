You are given ONE natural-language sentence describing ONE manufacturing step, and the structured JSON extraction of that same step. Verify the JSON against the sentence and return the CORRECTED single step.

# Output shape (STRICT)

Output ONE JSON object with EXACTLY these 6 keys and no others:

```
{
  "operation": "<string>",
  "machine": "<string>",
  "duration": "<string with units>",
  "precondition": [ {"component": "...", "component_type": "...", "container": "..."} ],
  "postcondition": [ {"component": "...", "component_type": "...", "container": "..."} ],
  "parameters": { "<key>": "<value>" }
}
```

- Do NOT wrap the result in a `"steps"` array. Return the step object directly.
- Do NOT return multiple objects, do NOT repeat the object.
- Do NOT include markdown code fences or any other text.
- If nothing needs to change, return the input JSON verbatim.

# What to correct

Only fix these three kinds of mistakes WITHIN this single step:

- **INCORRECT value**: a scalar in the JSON contradicts the sentence (wrong `machine`, wrong `duration` number/unit, wrong `operation`, wrong parameter value). Replace with the value stated in the sentence.
- **FABRICATED value**: a value in the JSON is not present in the sentence. Remove it (for `parameters` remove the key; for `precondition`/`postcondition` remove the item).
- **MISSING value**: the sentence explicitly names a value the JSON omits. Add it to the corresponding field.

Do NOT:
- Change formatting/casing of values that are already correct.
- Rewrite anything just because you could phrase it "better".
- Split this step into multiple steps or merge with another step (there is no other step to consider — you only see one).
- Reason out loud in the output.

# Duration convention

Duration numbers in the sentence are authoritative. If the sentence says "processing for N minutes", the duration is `"N minutes"` — even if the sentence mentions unrelated numbers (cycle time in seconds, feed rates, RPM). Do not swap a duration for an unrelated number that happened to appear nearby.
