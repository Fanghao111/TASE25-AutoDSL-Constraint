You are given structured JSON data extracted from process descriptions for a scheduling problem. Different extractions may use different field names and component names for the same concepts. Your task is to analyze the data and produce three outputs.

Here are a few sample JSON extractions:
---SAMPLES---

Here is the complete list of all unique field names found across all extractions:
---FIELD_NAMES---

Here is the complete list of all unique string values (component/material names) found across all extractions:
---COMPONENT_NAMES---

Your three tasks:

**Task 1: Field Name Normalization**
Group field names that refer to the same concept. For each group, pick one canonical name.
IMPORTANT: Only output groups with 2+ members (i.e., where actual merging happens). Do NOT output single-member groups or identity mappings.

**Task 2: Component Name Normalization**
Group component/material names that refer to the same thing. For each group, pick one canonical name (lowercase with spaces).
IMPORTANT: Only output groups with 2+ members. Do NOT output single-member groups.

**Task 3: Semantic Role Discovery**
These JSONs describe steps in a scheduling problem. Analyze the canonical field names and their values to discover which fields serve these roles:
- **resource**: which shared resource (e.g., equipment) is used by this step
- **duration**: how long this step takes (should be numeric values)
- **dependency_in**: what this step consumes/requires as input (enables precedence constraints)
- **dependency_out**: what this step produces as output (enables precedence constraints)
- **dependency_type_field**: the sub-field within dependency_in/dependency_out used for type matching
- **operation**: what action is performed
- **extra_params**: additional parameters/settings

For each role, specify the canonical field name and explain your reasoning.

Output ONLY a valid JSON object with this structure:
